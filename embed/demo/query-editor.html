<nubi-query-editor> demo

Open browser console to see emitted events. Scope gating is cosmetic — the server enforces the real gate.

Scenario 1 — SQL mode only (author:sql scope)

scopes: read:* author:sql | get-token: window.getTokenSqlOnly

Scenario 2 — Metric builder only (author:metric scope, no SQL)

scopes: read:* author:metric | get-token: window.getTokenMetricOnly

Scenario 3 — Full authoring (author:sql + author:metric)

scopes: read:* author:sql author:metric | get-token: window.getTokenBoth

Scenario 4 — Read-only (no authoring scopes)

scopes: read:* | get-token: window.getTokenReadOnly

Scenario 5 — Force read-only via attribute (overrides token scope)

scopes: read:* author:sql | attribute: read-only
